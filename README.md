# METRA IT Assets

Arabic-first Flutter application for IT inventory and custody management in the meteorological organization.

## Status
Initial project scaffold. Firebase credentials are intentionally not committed.

## Planned modules
- Offices and custody cards
- Asset catalog and technical specifications
- Asset movements and maintenance
- Inventory reports and Google Sheets export

## Setup
1. Install Flutter stable.
2. Run `flutter pub get`.
3. Configure Firebase using FlutterFire CLI (`flutterfire configure`).
4. Run `flutter run`.

See `docs/` for architecture and setup details.
